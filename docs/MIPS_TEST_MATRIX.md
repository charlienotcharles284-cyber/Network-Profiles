## 判定

连续 24～48 小时无异常，并且切网、后台恢复、UDP 和推送不弱于 gVisor，才考虑将 MIPS 用于主力配置。发生持续断流、DNS 异常、UDP 失败或 Network Extension 被系统终止时，保留日志并回到稳定版。
